## [ WHAT IS POKE OS ]

**Poke OS** is a lightweight, retro-inspired desktop environment built for Pokémon trainers and collectors. It combines the nostalgic Windows 95 aesthetic with modern web technology to create an immersive experience for exploring card collections, accessing terminal-based tools, and discovering hidden Poke Vault secrets.

**Why Windows 95?**
- Clean, familiar interface that doesn't require modern dependencies
- Period-accurate aesthetic that resonates with collectors
- Lightweight and performant — pure HTML/CSS/JavaScript
- Nostalgic throwback to the early web era

**Who is it for?**
- Pokémon card collectors organizing and researching collections
- Trainers exploring interactive terminal-based commands
- Retro enthusiasts who appreciate 90s web design
- Anyone curious about hidden Poke Vault secrets

**Core Philosophy:**
Simple. Accessible. No unnecessary frameworks. No bloat. Just a functional, beautiful retro desktop that works in any modern browser.

## [ THE POKE VAULT ]

Hidden within Poke OS is the **Poke Vault** — a distributed secret encoded across the system. Trainers can:

- Use the Poke Terminal to run `pokevault` command
- Explore mini-sites to find and collect shards
- Click cache markers to extract shard data
- Assemble recovered shards into the complete secret
- Verify vault integrity and unlock hidden rewards

The Poke Vault encourages exploration, terminal literacy, and attention to hidden system details.
